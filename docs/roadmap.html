Roadmap detail

Last reviewed: 2026-10-10 · Last updated: 2026-10-10 · Change: major (new file: milestones moved from ROADMAP.md, Current focus rewritten from the 2026-10-10 re-measure, beta milestones added) · Target: Adobe Premiere Pro 2026 (26.5.2)

Forward-looking plan: milestones with status, the current focus and what's next, with estimates in Opus 5.5 agent-hours (calibration in target-app-parity.md). The one-page summary is ROADMAP.md; the ranked work list is gaps.md. There is no cargo xtask scorecard or cargo xtask parity yet (G7).

Current focus

In order. Each item links to its gap entry, which says what "done" means.

  1. Stop launch crashes and add pull-request CI (G4): cargo xtask ci on macOS, Windows and Linux for every PR; old-macOS and Intel-GPU start-up. 40–80 h.
  2. Open .prproj (G2): the beta blocker. 60–120 h.
  3. 10-bit / 4:2:2 camera media in software (G3). 30–50 h.
  4. Fidelity harness against Premiere (G1) and cargo xtask parity (G7): turns estimates into measurements. 50–90 h.
  5. Real-world media corpus and workflow tests (G6). 40–70 h.
  6. Hardware acceleration, continued (#30, G5): zero-copy upload, Lumetri curves / wheels / HSL and keys on the GPU, VideoToolbox Main 10, Quick Sync / AMF encoders. 120–200 h.
  7. UI fidelity issues (G8): Program monitor transform handles, Effect Controls, docking. 120–200 h.
